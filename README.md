# lolo 桌宠 🐻

一个会陪在你桌面上的小熊桌宠：支持提醒、番茄钟、面板、托盘菜单，桌面常驻不占地。

> 🌐 **国内打不开 github.com？** 用**反代直链 `ghfast.top`**（已实测可用，文件类都通）：
> 把任意 `https://github.com/...` 链接整个前面拼上 `https://ghfast.top/` 即可打开。
> 例：`https://ghfast.top/https://github.com/bobobizzz/lolo-pet/releases`
> ⚠️ 反代**只代理文件、不代理网页**；要看说明文档请用下方「文档直读」链接（纯文本，手机电脑都能看）。

## 下载安装

### Windows 用户（最简单）
前往 Releases 下载 `.exe` 安装包：
- 原站：https://github.com/bobobizzz/lolo-pet/releases
- 反代：https://ghfast.top/https://github.com/bobobizzz/lolo-pet/releases
下载卡住时用反代直链（原链接前拼 `https://ghfast.top/`）：
- 安装版：https://ghfast.top/https://github.com/bobobizzz/lolo-pet/releases/latest/download/lolo-win-setup.exe
- 便携版：https://ghfast.top/https://github.com/bobobizzz/lolo-pet/releases/latest/download/lolo-win-portable.exe

### Mac 用户（走「源码运行」）
macOS 会拦截未公证的软件，Mac 不提供直接安装包，请改用**源码运行**：
1. 打开「终端」（Command+空格 → 搜「终端」→ 回车），粘贴下面这一行并回车，脚本会自动下载源码、装依赖、生成桌面「启动lolo」并直接启动：

   ```bash
   curl -sL https://ghfast.top/https://raw.githubusercontent.com/bobobizzz/lolo/main/install-mac.sh | bash
   ```

2. 📘 完整图文教程（反代直读，好打开）：
   https://ghfast.top/https://raw.githubusercontent.com/bobobizzz/lolo-pet/main/Mac-源码运行指引.md
   （本仓库 Release 附件里也有 `Mac-tutorial.md` 可下载）

> 首次打开 macOS 会弹「无法验证开发者」，属正常现象，按脚本引导放行一次即可，以后不再拦。
